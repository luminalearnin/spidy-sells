# Spidy Sells

Premium editorial storefront for Spidy Sells, an artisanal tiramisu boutique born in Park Circus, Kolkata.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The storefront is intentionally front-end first: cart state, OTP sign-in, batch countdown, fulfillment slots, UPI handoff, and WhatsApp confirmation are all implemented as responsive interaction patterns ready to connect to live commerce services.
